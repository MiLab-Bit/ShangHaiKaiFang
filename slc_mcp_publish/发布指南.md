# 发布到腾讯云 MCP 广场（cloud.tencent.com/developer/mcp）操作指南

> 目标：把「上海图书馆开放数据」MCP 从本地 stdio 服务发布成公网 Streamable HTTP 服务，
> 且**发布代码里不含你的 APIKey**（每个使用者传自己的 Key）。

---

## 前置准备（一次性）

1. **开通云开发环境**：前往 https://tcb.cloud.tencent.com 开通 CloudBase（有免费额度），创建一个环境（记下"环境ID"）。
2. **本地安装 Node.js LTS**（部署工具用）：https://nodejs.org
3. 本地安装 `@cloudbase/cli` 并登录：

```bash
npm i -g @cloudbase/cli@latest
tcb login     # 会打开浏览器，扫码/账号登录
```

---

## 第 1 步：在云开发控制台创建空白 MCP Server

1. 打开 https://tcb.cloud.tencent.com/dev#/ai?tab=mcp
2. 点击「创建 MCP Server」→ 选 **空白模板**
3. 填写：名称（如 `上海图书馆开放数据`）、服务标识（如 `shanghai-library-opendata`）
4. 系统会自动创建一个云托管服务承载它（记下服务名）

> 这一步的云托管服务，后面会用我们仓库里的 Dockerfile 覆盖部署。

---

## 第 2 步：准备发布代码（本仓库 slc_mcp_publish/ 已备好）

目录结构：

```
slc_mcp_publish/
├── Dockerfile          # 官方模板适配：node:20-alpine + python3 + @cloudbase/mcp-transformer
├── mcp-meta.json       # 服务元信息（上架用，按控制台提示微调）
├── DOC.md              # 接入文档（上架必填）
└── app/
    ├── slc_mcp_server.py   # MCP 服务（v1.3.0，纯标准库，零 Key）
    └── slc_endpoints.py    # 97 个接口注册表
```

**Key 已确认不在此目录**（此前已用 grep 校验）。服务读取 Key 的优先级：
`工具参数 key`（每个调用者传自己的） > 环境变量 `SLC_API_KEY`（可选，服务端统一指定）。

---

## 第 3 步：本地先验证 Docker 镜像（可选但推荐）

```bash
cd slc_mcp_publish
docker build -t slc-mcp:test .
docker run --rm -p 3000:80 slc-mcp:test
```

然后用 MCP Inspector 或任意 Streamable HTTP 客户端连 `http://127.0.0.1:3000/messages` 验证工具可用。

> 本地调试 stdio 形态也可用官方 inspector：
> `npx -y @modelcontextprotocol/inspector`（Transport 选 STDIO，Command 填 `python3`，Args 填 `app/slc_mcp_server.py`）

---

## 第 4 步：部署到云托管

```bash
cd slc_mcp_publish        # Dockerfile 所在目录
tcb cloudrun deploy
```

按提示选择：云开发**环境ID** + **云托管服务名**（第 1 步创建的那个）。CLI 会自动构建镜像并部署。

### （可选）配置环境变量
- 若想让服务端统一使用某把 Key：在云托管「服务详情 → 环境变量」里加 `SLC_API_KEY=你的Key`。
- **发布版建议不配置**：让每个调用者通过工具参数 `key` 传自己的 Key，你的 Key 永不外泄。

---

## 第 5 步：测试线上服务

1. 云开发 MCP Server 详情页 → `Tools` 标签 → 应能看到 12 个工具，可直接调用测试。
2. 在 Cursor / Claude Desktop / WorkBuddy 里添加 **Streamable HTTP** 类型服务，
   URL 填 `https://<部署得到的域名>/messages`，连接后 `List Tools` 应显示 12 个工具。
3. 免 Key 工具直接可用（`souyun_poem` 查一首"江南"主题的诗试试）。

---

## 第 6 步：发布上架到 MCP 市场（MCP 广场）

1. 云开发 MCP Server 详情页 → 找到「**发布上架**」入口（docs.cloudbase.net/ai/mcp/develop/publish）
2. 按向导填写：名称、图标、分类、简介；上传 `DOC.md` 作为接入文档；上传 `mcp-meta.json`（字段以向导提示为准，本仓库提供参考模板）
3. 提交审核（一般 1~3 个工作日）
4. 审核通过后，你的服务会出现在 **https://cloud.tencent.com/developer/mcp**（开发者 MCP 广场），其他人可一键连接使用。

---

## 安全与合规提醒

- ✅ 已做到：发布代码零 Key；Key 由每个调用者自行提供。
- ⚠️ 上图书竞赛 Key 约定"仅限本届竞赛非商业使用"，请勿把自己的 Key 配置到公开服务的环境变量里（否则等于把 Key 暴露给所有调用者）。
- ⚠️ 若要做成"无 Key 也能用的公开服务"，可只上架**搜韵免 token 工具**（souyun_poem/rhyme/couplet），它们在 DOC.md 中已说明。
- 腾讯云云托管本身支持 ApiKey 鉴权，可限制只有你授权的人能调用该服务。

---

## 故障排查

| 现象 | 处理 |
|---|---|
| 部署后 Tools 空白 | 在服务详情页看运行日志；确认 Dockerfile 中 `--stdioCmd "python3 /app/slc_mcp_server.py"` 路径正确 |
| 调用 slc_* 返回"缺少 APIKey" | 客户端调用时在工具参数里传 `key`（自己的竞赛 Key） |
| 本地连接不上 | 检查端口占用；用 inspector F12 看请求详情 |
| 上架被驳回 | 通常缺 DOC.md 或 mcp-meta.json 字段不完整，按驳回理由补 |
